# ai-coding-rules

A local-first CLI that scans your project and generates evidence-backed instruction files for AI coding agents — `AGENTS.md`, `CLAUDE.md`, Cursor rules, GitHub Copilot instructions — and lints them for duplicates, contradictions and stale references.

- Detects your stack: Flutter, React, Next.js, NestJS, Laravel, and more
- Every generated rule cites the file it came from
- `doctor` finds conflicts between instruction files and between files and your repo
- Runs locally, works offline, no API key required

> **Status:** planning. See [PLAN.md](./PLAN.md) for the design and roadmap. Feedback and contributions are welcome.
